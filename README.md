# 🌌 Selecto Spectrum: Eclipse

> *"Who decides what the world becomes?"*

A choice-driven terminal adventure game built in **C++**, where every decision influences hidden traits, relationships, and the ending you receive.

Originally developed as a college project, Selecto Spectrum: Eclipse evolved into an interactive narrative experience inspired by choice-based storytelling.

---

## 🎮 About the Game

During the **Silent Eclipse**, you awaken near the Eclipse Monastery with fragmented memories and a mysterious mark glowing on your hand.

The legendary **Spectrum Heart** has awakened.

Along your journey, you will encounter:

* **Elira Venn** – A Memory Cartographer who can restore forgotten truths.
* **Cassian Thorne** – A former Royal Inquisitor seeking redemption.
* **Nyra Vale** – A smuggler whose loyalty is never straightforward.
* **Brother Oren** – A monk who believes hope still matters.
* **Vaelis** – A man who believes destiny should be controlled, not trusted.

Every choice shapes not only your fate, but the fate of those around you.

## 🚀 How to Run

### Option 1: Run the EXE (Recommended)

1. Download `SelectoSpectrum.exe`
2. Double-click the file.
3. If Windows SmartScreen appears:

   * Click **More Info**
   * Click **Run Anyway**
4. Enjoy the game.

### Option 2: Compile from Source

Requirements:

* g++
* VS Code (optional)

Compile:

```bash
g++ main.cpp -o SelectoSpectrum.exe
```

Run:

```bash
.\SelectoSpectrum.exe
```
